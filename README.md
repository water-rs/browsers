# waterui-browsers

CEF and WPE WebKit browser engine realizations for WaterUI:
- `waterui-browser-cef`: Shared Chromium Embedded Framework realization for macOS, Linux, and Windows.
- `waterui-browser-wpe`: Bundled WPE WebKit realization for Linux.
